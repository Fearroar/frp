# Mingchi FRP WMS Server · 1.1.0 (MySQL 5.7.44)

发布日期：2026-10-15

## 本次实现

- 真实 PHP 8.2+ / MySQL 数据库、首次安装向导、邮箱或手机号登录、密码哈希及强制首次修改、员工角色和服务端权限。
- 产品SKU自动编号、规格与颜色/材质分离、产品图片、工厂/货权、仓库、批次质量等级、库存安全阈值。
- 带事务锁的入库、出库、盘点、订单预留与仓库调拨；流水和审计。
- 客户管理、CSV模板/字段映射导入、客户标签筛选、商机来源/预计金额/预计成本/状态/转化金额。
- 订单收入/产品成本/直接费用/收款记录，公司经营费用独立登记，人民币期间盈亏看板。
- 即时报价计算器，人民币成本、手动外币汇率、自定义费用、贸易术语及保存报价。
- 品牌Logo/配色、主菜单与设置子栏目排序、内置字段编辑、自定义字段、选项分类、老板看板指标。

## 需要目标服务器完成的验证

本环境能够执行PHP和前端浏览器测试，但未提供 MySQL 服务及 `pdo_mysql` 扩展，因此没有进行真实数据库安装、多人并发压力测试或正式服务器安全审计。上线前务必完成 `docs/ACCEPTANCE.md` 的全套测试。

## 已知范围

- 报表是内部管理口径，不是税务会计系统；无自动实时外汇API。
- 客户支持CSV字段映射；暂未提供Excel XLSX解析及其他业务表的批量迁移。
- 核心业务数据关系和库存事务算法不可在设置中删除，以确保数据一致性。
- 自定义字段支持常见类型；复杂的可编程自定义公式/任意新增业务模块不在1.0范围。
- 大规模企业数据库可视情况后续增加更深入的分页筛选、操作审批及异地容灾。

## 1.1.0 数据库兼容性更新（2026-10-15）

- 目标版本从 MySQL 8.0+ 改为 MySQL 5.7.44。
- 去掉 MySQL 5.7 不执行的 `CHECK` 声明；服务端保留事务和库存非负校验。
- 将 `reference_values` 的值字段限制为 150 字符，组合唯一索引 (40+150)×4=760 字节，以兼容 767 字节 InnoDB 索引环境。
- 在选项配置 API 中增加 150 字符限制，防止写入时发生截断。
- 首次安装提前验证 MySQL 版本和数据库为空，以免误装或部分覆盖。
- 更新宝塔部署指南、README 和兼容性测试指引。
- 本环境未运行 MySQL 5.7.44 实例，真实安装与并发功能仍需用户服务器测试。
