# 宝塔面板部署图文式步骤（文字版）

适用：Linux 宝塔面板 / Nginx / PHP 8.2+ / **MySQL 5.7.44**。

### 01. 创建数据库

首先在宝塔的「数据库 → MySQL」确认服务器版本为 **5.7.44**（可以执行 `SELECT VERSION();`）。然后在「添加数据库」中创建全新的空库 `mingchi_wms`。建议使用随机密码，字符集选择 `utf8mb4`。**不要使用 WordPress 正在运行的数据库。**

### 02. 上传项目

将下载的 ZIP 压缩包上传到 `/www/wwwroot/`，解压后应得到：

```text
/www/wwwroot/mingchi_wms_server/
├── app/                    PHP 业务逻辑
├── database/schema.sql     MySQL 建表结构
├── docs/                    部署和验收文档
├── public/                  唯一允许作为站点根目录的文件夹
│   ├── index.php            Web入口
│   ├── install.php          首次安装向导（安装后删除）
│   ├── api.php              后端接口
│   ├── media.php            带登录保护的图片读取
│   └── assets/              JS/CSS
├── storage/uploads/         上传图片目录
└── README.md
```

### 03. 设置站点

宝塔「网站 → PHP项目」新增 IP 对应的网站。如果你不需要域名，填写服务器 IP 或按宝塔支持的 IP:端口形式创建，确保防火墙开放该端口。PHP版本选择8.2或以上。

**最关键的一项：** 将网站的「运行目录/网站目录」设置成 `.../mingchi_wms_server/public`，不要使用 `.../mingchi_wms_server`。否则 PHP 配置及上传目录可能暴露。

PHP 扩展必须具备 `pdo_mysql`、`fileinfo`、`openssl`，建议 `mbstring`。建议启用 `opcache`。

### 04. 安装与登录

浏览器访问 `http://IP/install.php`，填写数据库主机（通常是127.0.0.1）、端口3306、数据库名、数据库用户及密码，设置超级管理员邮箱和长密码。安装程序先核对 MySQL 版本及是否空库，再建表并初始化字段、类别、默认工厂及默认仓库。若以前安装失败留下部分表，请先备份，并改用新的空数据库重试。

若报“config.local.php无法写入”，仅在安装期间赋予网站运行账户对项目根目录的写入权限，成功后恢复权限，禁止777目录权限。

安装成功后**删除 `public/install.php`**，使用超级管理员邮箱登录。

### 05. 创建员工

进入「员工与权限 → 创建员工子账号」填写姓名、邮箱/手机号、角色、初始密码，并勾选可访问和可修改的功能。员工首次登录须修改密码。

建议老板账号拥有财务查看权限，业务员只拥有需要的库存、客户、商机与报价权限，仓库员工只拥有批次和出入库权限。

### 06. 正式启用前

先将 `docs/ACCEPTANCE.md` 中的用例在**测试数据**上全部完成，尤其是并发出库、库存调拨、人民币汇率快照、客户导入和费用核算。上线后配置 MySQL定时备份与图片目录备份。若需要跨公司外网访问，优先通过 HTTPS + VPN，不要裸露 HTTP 登录。

### MySQL 5.7.44 兼容性注意

- PHP 可使用 8.2+，但必须启用与 PHP 对应的 `pdo_mysql` 扩展。
- MySQL 5.7 不会执行 `CHECK` 约束；系统库存安全通过 PHP 服务端校验和 InnoDB 事务锁保证，请勿直接用 SQL 修改库存。
- 需要有新建表与索引权限，数据库字符集使用 `utf8mb4`。
- 不要覆盖 WordPress 数据库或已存在库存记录的库。
- 查看 `docs/MYSQL57_COMPATIBILITY.md` 的详细说明及排错。
