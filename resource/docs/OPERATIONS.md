# 使用说明与核算口径

## 工作步骤

1. 管理员在「工厂与货权」建自有工厂、合作伙伴等主体，再在「仓库管理」建立实际仓库。
2. 仓库人员新增产品档案（产品名称、规格、颜色、材质、单位），系统生成唯一SKU。
3. 新建库存批次，关联产品、货权主体、存放仓库、质量等级、成本价和照片；初始库存为0。
4. 执行「入库」增加数量。发货时在「出库」选择客户及订单，记录真实扣减。调拨必须走「仓库调拨」，不能直接篡改批次数量。
5. 外贸人员录入客户与询盘（可以CSV导入客户）。在商机中记录来源、预计成交额、预计成本、阶段及概率。
6. 商机成交后建立订单，关联客户和商机，填写原币销售金额和手动参考汇率。订单详情记录产品成本、直接费用、实际收款、库存预留。
7. 公司广告费用、工资、房租等在「经营费用」单独录入。看板按选定日期范围估算公司经营盈亏。
8. 外贸人员可随时使用「即时报价计算器」独立测算。保存报价不产生库存出入库、也不会自动创建订单。

## 设计保护与局限

- 产品、客户、商机、订单、批次的自定义字段按固定`field_key`绑定。改名、调整显示顺序不会交换字段的实际存储值。
- 库存数量只能通过事务型出入库、订单预留和仓库调拨修改。历史出入库记录不会直接被员工删除。
- 经营盈亏是简化管理口径，并非税务/会计审计口径。仓储折旧、所得税、出口退税等如需纳入，请在正确的费用类别中手动填报。
- 只有订单被关联到商机时才构成可追溯的已转化金额；无法从现有系统自动推断广告关键词与订单的关联。
- 出口订单币种可选择美元等，并手动设置1单位外币对应人民币数额。汇率按订单、报价、收款分别留存，默认汇率更新不会倒改历史金额。
- 客户CSV中只有默认字段可以直接映射导入。复杂自定义字段需要后续迁移工具或通过界面建档。
- 列表数据通过 API 分页读取，每页50条；关系选择菜单一次加载前100条。如数据量明显超过数千客户/批次，建议升级为服务端关键词搜索的关联弹窗。
- 非财务人员只能查看由管理员授权的成本与利润数据。
