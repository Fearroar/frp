# 上线前验收清单（推荐在宝塔测试站完成）

**请使用测试数据逐项验收，再录入正式客户及库存。** 本文分为功能验收与服务器安全验收。

## A. 安装与访问

- [ ] `public` 为网站根目录，`/install.php` 可完成空库建表及创建超级管理员。
- [ ] 安装后将 `public/install.php` 从服务器删除，再次访问不能重新安装。
- [ ] 两台不同电脑访问同一 IP/域名，能看到相同产品和库存变更。
- [ ] 员工账号既可通过邮箱也可通过手机号 + 密码登录。
- [ ] 登录失败 8 次后受到限制；员工首次登录需修改初始密码。
- [ ] 禁用账号后无法继续读取 API / 上传资料。
- [ ] 普通业务员无法越权调用设置、员工管理和库存写入 API。

## B. 产品、仓库和库存

- [ ] 新建两条同规格但不同颜色的产品，SKU 自动生成且各自唯一。
- [ ] 新建自有工厂、合作工厂、各自仓库；库存列表能显示货权主体和存放仓库。
- [ ] 创建批次并上传实拍图，列表可打开大图预览。
- [ ] 新建批次初始库存为0；入库100，库存为100；出库20，库存为80。
- [ ] 测试两人并发同批次出库时，不会出现负库存或重复扣减。
- [ ] 为某订单预留50后，其余订单只能使用未预留的30；释放预留后可用数量恢复。
- [ ] 从工厂A向工厂B调拨10，两个仓库数量对应变化且留下双向流水。
- [ ] 安全库存阈值大于可用库存时，低库存统计有变化。
- [ ] 出入库弹窗在100%浏览器缩放下能滚动到底部且按钮始终可点击。

## C. 客户、商机与订单

- [ ] 客户 CSV 导入中文模板，UTF-8、GBK 版本均识别表头；可调整字段映射。
- [ ] 客户标签可配置；按标签筛选客户。
- [ ] 新建商机，填写来源、预计金额、成本、概率；潜在利润正确。
- [ ] 新建订单关联商机，商机转化金额正确；未成交商机不计入实际订单收入。
- [ ] 订单产品明细、订单直接费用、公司期间费用分开记账。
- [ ] 订单收款可分两次登记，每次填写独立实际结汇汇率。

## D. 经营核算/人民币汇率

- [ ] 订单 USD 1000、汇率7.2：人民币订单收入应为 ¥7200。
- [ ] 产品及直接成本人民币5000：订单贡献利润应为 ¥2200。
- [ ] 公司广告等当期经营费用人民币600：公司当期经营盈亏估算应为 ¥1600（仅有该订单、该费用时）。
- [ ] 将系统默认汇率改为7.0，历史订单仍保持之前保存的7.2。
- [ ] 选择当月或自定义日期范围，看板统计口径与订单日期/费用日期一致。
- [ ] 取消订单不应计入正式的经营收入；修改取消状态名称后，旧记录仍正确统计。

## E. 即时报价计算器

- [ ] 人民币产品单位成本100、数量100、其他费用人民币1000、目标毛利率20%、无佣金、汇率7.20，则：
  - 总直接成本 ¥11,000；
  - 人民币建议报价 ¥13,750；
  - 报价 USD 1,909.72（四舍五入到分）；
  - 人民币预计贡献利润 ¥2,750。
- [ ] 选择批次时能够带出正确成本（前提是账号有相应成本查看权限）。
- [ ] 添加、删除自定义费用时其他已输入的报价参数保持不变。
- [ ] 保存报价后可以在最近报价中查看保存时的汇率与利润，不影响库存数量。

## F. 配置中心

- [ ] 修改公司名称、上传Logo、更改主题色，刷新登录后保持。
- [ ] 主菜单、设置子栏目及看板卡片可以调整顺序。
- [ ] 将内置“颜色”移至“材质”前后多次，不会出现材质显示为颜色的问题。
- [ ] 新增下拉自定义字段并配置选项，填写后能在编辑表单和列表中重新找到对应值。
- [ ] 普通自定义字段停用后历史数据未被直接删除，可以恢复启用。
- [ ] 改名质量等级、商机状态或费用类别后，旧记录能保留业务关系。
- [ ] 核心字段不可删除或修改数据类型，库存安全规则无法被任意关闭。

## G. 安全备份

- [ ] 数据库计划备份、图片目录备份、配置文件备份均正常。
- [ ] 从备份在另一个测试站恢复，验证库存、用户、产品图片完整。
- [ ] 服务器 PHP错误日志没有高频错误，Nginx访问日志没有 `/app/` 或 `/storage/` 目录泄漏。
- [ ] 系统通过 HTTPS 提供服务，重要密码未上传到聊天或客户表。
- [ ] 使用测试数据完成至少一整套「产品→入库→商机→订单→出库→利润→看板」流程。
