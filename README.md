# 明驰 FRP 库存管理系统（MySQL 5.7.44 兼容版）

适用：PHP 8.2+、**MySQL 5.7.44**、Nginx/Apache、HTTPS。安装程序也接受 MySQL 8.0+；本次兼容包未覆盖 MariaDB。

此版本是独立的前后端全栈应用，不再将业务数据存放在浏览器 localStorage 中。界面中文，服务器端存储和校验，多员工共享数据库，独立角色权限。

## 宝塔面板首次部署（IP访问也可以）

1. 在宝塔「网站 → PHP项目」创建一个网站，域名可填写服务器的IP（或IP加端口，按面板支持方式）。选择 PHP 8.2 或以上版本，启用 `pdo_mysql`、`fileinfo`、`openssl`，推荐 `mbstring`。
2. 创建一个 **全新的空 MySQL 5.7.44 数据库**，记下数据库名、用户名和密码。数据库字符集 `utf8mb4`。
3. 解压整个项目到 `/www/wwwroot/mingchi-wms`（路径可以不同），不要只上传 public 目录。
4. **站点根目录必须指向 `/www/wwwroot/mingchi-wms/public`**，不能指向项目上一级目录，避免泄漏配置文件和数据文件。
5. PHP运行账户需能够写入项目根目录 `config.local.php`（安装时）以及 `storage/uploads`，并能创建 `storage/.installed`。安装后收紧 `config.local.php` 文件权限。
6. 网站采用 PHP 默认静态资源路径，无需特别的 SPA 伪静态规则。访问 `http://服务器IP/install.php`，填写数据库连接信息及超级管理员邮箱和密码完成安装。
7. **安装完后立即删除 `/public/install.php`**。站点若向公网开放，请配置 HTTPS、访问限制、WAF/限流与数据库备份。
8. 登录后在「系统设置」配置公司 Logo、菜单、字段、费用、汇率等。首次创建员工账号时使用单独的初始密码，员工登录后强制修改。

### 推荐 Nginx 配置（在已有宝塔 vhost server 中添加）

```nginx
location ~ /\.(?!well-known) { deny all; }
location ~* \.(?:sql|log|bak|ini)$ { deny all; }
client_max_body_size 6m;
```

宝塔自己生成的 PHP-FPM 转发配置应保留，禁止展示目录索引。启用 HTTPS 后才建议员工从公网登录。

## 数据核算口径

- 所有产品成本、经营费用以 **人民币（CNY）** 保存。
- 商机/订单可以用 USD 等交易币种输入，保存时固定写入 `fx_to_cny` 参考汇率；历史记录不会随着系统默认汇率变化而重算。
- 订单贡献利润 = 订单销售金额 × 保存汇率 − 订单产品明细成本 − 订单直接费用。
- 当期经营盈亏估算 = 期间订单贡献利润 − 期间公司经营费用；订单按订单日期，经营费用按费用日期。
- 实际收款另存每笔付款原币金额及实际结汇汇率，按照收款日期统计现金收入，不等同于当期订单销售额。
- 商机预计金额仅用于管道分析，不自动计入订单收入；商机关联订单后显示转化金额。
- 非财务会计软件，暂不自动计算退税、税务、应收账龄和存货结转，统计口径用于内部经营决策。

## 权限与自定义

- 超级管理员创建普通管理员、仓库人员、业务人员，按具体权限逐项授予。
- 设置中心可更改品牌名称和 Logo，编辑/排序/隐藏菜单、内置字段的名称/显示/顺序、新增自定义字段，以及自定义选项和经营费用类别。
- 字段 `field_key` 永不跟显示位置绑定；例如颜色和材质对调显示顺序，不会发生值串位。
- 核心业务字段（产品编号、货权、仓库、数量、订单币种及汇率等）不可删除或改数据类型，以确保历史数据和库存一致性。

## 备份与安全

- 数据应采用每天的 MySQL 自动备份，另行备份 `storage/uploads` 和 `config.local.php`。**只有数据库备份而没有图片目录无法恢复完整系统。**
- 参考：`mysqldump --single-transaction --default-character-set=utf8mb4 -u USER -p DBNAME > wms-backup.sql`。
- 备份文件不要放在可被网站访问的 public 目录；建议有异地备份和定期恢复演练。
- 上传文件只允许经服务端验证的图片类型，文件名随机，图片通过需登录的 PHP 入口读取。

## 数据迁移

以往 V2–V5 是 `localStorage` 本地 HTML 原型。新系统使用 MySQL，**不会自动继承演示版的数据**。客户可以导出 CSV，通过新系统进行字段映射导入；其他演示数据必须先校验、清洗后再建档。不要导入演示用的虚构数据作为正式台账。

## 验收与后续维护

- 安装完成后，建议按 `docs/ACCEPTANCE.md` 做真实服务器测试。
- 数据库结构已按 MySQL 5.7.44 调整。MySQL 5.7 不执行 `CHECK` 约束，所有库存数量变更只允许通过应用接口执行；严禁手动修改库存数量。后续升级须先备份，并提供迁移 SQL，不能直接覆盖库表或重复运行安装向导。
- 若必须走完全离线的内网IP访问，可使用 HTTP；但登录密码和业务资料会在内网明文传输，推荐在内网也使用 HTTPS 或可信的 VPN 接入。

## MySQL 5.7.44 适配提示

- 检测数据库版本：在宝塔数据库终端执行 `SELECT VERSION();`，预期包含 `5.7.44`。
- 适配内容：去除无效的 `CHECK` 语句、缩小 `reference_values` 组合唯一索引到 767 字节范围内、安装前验证版本和空库状态。
- 如果此前安装报错后在库中留下了若干表，**先备份并核对是否有数据**，然后创建新的空数据库进行安装；不要在已有业务库上重复安装。
- 数据库服务器仅建议监听内网或 localhost；MySQL 5.7 已过常规维护期，应限制公网访问、加强备份。
- 更多说明参见 `docs/MYSQL57_COMPATIBILITY.md`。
